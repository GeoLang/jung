Jung

A high-performance geospatial symbology and cartographic rendering engine written in Rust.

Rust WebAssembly GPU (Vello/wgpu) Mapbox GL Compatible OGC Standards AGPL-3.0-or-later

Features

What the renderer actually draws. Renderer::render covers points, lines and polygons from a Mapbox GL style, with hard-edged integer rasterization, plus labels from the text-* properties once you hand it a font. Cards marked library only are modules with their own tests that nothing on the render path calls: you have to call them yourself.

The CLI and the WebAssembly build both read GeoJSON through jung_core::geojson, which covers every geometry type. A GeometryCollection becomes one feature per member. Feature properties come through, except arrays and objects, which are dropped.

GPU Accelerated

Builds a Vello scene graph from styled features. Hand it to your own wgpu renderer to draw on the GPU.

Mapbox GL Compatible

Full expression language: data-driven styling, zoom interpolation, property-based filters. Drop-in style compatibility.

OGC Standards library only

WKT/WKB serialization, Simple Features operations (envelope, area, length, centroid), SLD/SE 1.1 import and export. Filter predicates are a Rust enum and evaluator, not OGC Filter Encoding, whose XML is neither read nor written. SLD import matches rules as the literal <se:Rule, so another namespace prefix yields zero rules with no error, and it never parses filters, so imported rules match every feature.

Anti-Aliasing library only

Xiaolin Wu line AA, distance-based thick lines, polygon coverage, smooth circle edges. antialias.rs implements all of it and nothing calls it, the render path is hard-edged.

Advanced Symbology library only

MIL-STD-2525 military, S-52/S-57 maritime, topographic contours/hillshade, graduated/classified, heatmaps, clustering. All of it exists as callable modules, none of it is reachable from Renderer::render. The MIL-STD symbols have no glyph set, every unit of one affiliation draws as the same empty frame.

Labels

Renderer::render draws a style's text-field once you give it a font with with_fonts: TrueType glyphs from text.rs, priority deconfliction from label_priority.rs, and text turned along line features by curved_label.rs. Point and line features label, polygons do not. Without a font nothing is drawn and text_layers_without_font names the layers skipped. The 5x7 bitmap LabelEngine in label.rs is still library only.

Vector Tiles (MVT)

Protobuf decoder for Mapbox Vector Tiles with thiserror its only dependency. Geometry command parsing, zigzag decoding, attribute extraction.

Outputs

RGBA pixels and a Vello scene graph for your own wgpu renderer, which carries geometry only and no labels. Renderer takes no DPI or scale factor, so a 1px line stays 1px however large the buffer.

GeoLang Ecosystem

Ptolemy uses jung-esri to translate an ArcGIS drawingInfo into Mapbox GL style layers. TerraVista uses jung-mvt to decode vector tiles. Fenestra can build a Vello scene behind an optional feature the platform deploy does not enable. ViewTopia does not import jung-wasm, its client styling is MapLibre and Cesium.

Quick Start

use jung_core::renderer::{BBox, Renderer};
use jung_style::parse_style;

let style = parse_style(r#"{
    "layers": [{
        "id": "cities",
        "paint": { "circle-color": "#ff0000", "circle-radius": 5.0 }
    }]
}"#).unwrap();

let renderer = Renderer::new(512, 512).unwrap();
let bbox = BBox { min_x: -180.0, min_y: -90.0, max_x: 180.0, max_y: 90.0 };
let pixels = renderer.render(&style, &features, &bbox).unwrap();
